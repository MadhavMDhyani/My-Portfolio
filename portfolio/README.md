## 💻 Portfolio Web Architecture

This repository contains the source code for my interactive portfolio, architected with a dark-only liquid glass design system:

```text
Portfolio Website/
├── portfolio/
│   ├── public/              # Static assets, favicon, robots.txt, sitemap.xml
│   ├── src/
│   │   ├── assets/          # Compressed images and logos
│   │   ├── components/      # 3D Three.js canvas, Glass UI primitives, TiltCard, Navbar
│   │   ├── sections/        # Hero, AboutMe, TechnicalProficiency, Projects, ContactMe
│   │   ├── utils/           # Project data, tokens, navigation links
│   │   ├── App.jsx          # Root component with stacking context isolation
│   │   ├── index.css        # Tailwind directives and custom liquid glass CSS
│   │   └── main.jsx         # Application entry point
│   ├── index.html           # Optimized entry point with absolute OpenGraph SEO metadata
│   ├── tailwind.config.js   # Dynamic RGB channel colors with alpha transparency
│   └── vite.config.js       # Rolldown / Vite bundler configuration
└── README.md                # Repository documentation & professional profile
```

### Local Development Setup

To run the portfolio locally on your machine:

```bash
# Navigate to the portfolio project directory
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

# Run linting
npm run lint

# Build production bundle
npm run build
```
