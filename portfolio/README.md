# Madhav Dhyani - Developer Portfolio

A modern, high-performance portfolio showcasing scalable backend architectures, full-stack systems, and interactive 3D web experiences.

- **Live URL**: https://madhav-dhyani.vercel.app

## Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Three.js**
- **EmailJS**

## Getting Started

To run the project locally:

```bash
cd portfolio
npm install
npm run dev
```
